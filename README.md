# Ballers Score - GitHub Pages

Estrutura:

- index.html
- audios.json
- audios/
  - seus arquivos .mp3

## Como adicionar áudio

1. Faça upload do MP3 para a pasta `audios/`.
2. Abra `audios.json`.
3. Adicione o nome exato do arquivo.

Exemplo:

```json
{
  "audios": [
    "cesta1.mp3",
    "cesta2.mp3",
    "sirene.mp3"
  ]
}
```

4. Faça Commit.
5. Recarregue o site no PC ou celular.

Os dois dispositivos usam os mesmos arquivos do GitHub Pages.
